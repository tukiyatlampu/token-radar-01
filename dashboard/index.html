How implied value is computed

One function scores every protocol from snapshot figures only; no name is special-cased.

implied = max(1, round(Teff × category multiple × growth multiplier × maturity multiplier × chain multiplier))

Teff is log-scaled effective TVL: large TVL still counts, but each extra dollar counts less, so size alone cannot dominate the ranking. The category multiple starts from the geometric-mean mcap/TVL ratio of live-token peers in the same category, blended toward the shrunk global multiple in log space (weight 0.15 × n/(n+12)); the global blends the cohort geomean toward a fixed 0.2 prior (0.2), then clamps. No live peers → the global multiple. Growth is asymmetric — falls hurt more than rises help — but all three factors are damped to 0.05, so they barely move the ranking.

Exact equations

  • Teff = 250,000,000 × ln(1 + TVL / 250,000,000)
  • growth = exp(1.8 × min(x, 0) + 0.55 × max(x, 0)), clamped to [0.35, 1.5], then ^0.05, where x = clamp(change_7d / 100, −0.6, 1.2); missing change → x = 0
  • maturity = 0.55 + 0.45 × (1 − exp(−age_days / 540)), then ^0.05; missing listing date → age = 365 days
  • chain = 1 + 0.04 × log2(min(max(chains, 1), 8)), then ^0.05
  • multiple = exp(w × ln(category geomean) + (1 − w) × ln(global multiple)), w = 0.15 × n / (n + 12), n = live peers in the category, r = clamp(mcap / TVL, 0.02, 3) for every geomean, clamped to [max(0.02, 0.25 × global multiple), min(3, 4 × global multiple)]; global multiple = exp(0.2 × ln(cohort geomean) + 0.8 × ln(0.2))

What the ranking is for: the factors are heuristic preferences, not fitted predictors — they encode what a token-launch hunter wants to surface: higher-multiple categories, downside-weighted momentum, longest time since listing, multi-chain presence. Held-out market-cap prediction is not the objective; discovery is. The constants were tuned on this cohort's leave-one-out diagnostics, so the check below is a development diagnostic, not a generalization claim — the model beats the starter on both MedAPE and Spearman, by a small margin.

Missing-data assumptions

  • Seven-day change missing → neutral, marked “n/a”.
  • Listing date missing → age 365 days (maturity ≈0.99×), shown “unknown”.
  • No chains listed → no chain bonus.
  • Category with no live-token peers → shrunk global multiple.
